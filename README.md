# Le Carnet à Points

Jeu de "points à relier" progressif pour enfants, en ligne, sans serveur ni base de données.

## Mise en ligne sur GitHub Pages

1. Crée un nouveau dépôt public sur GitHub (ex: `carnet-a-points`).
2. Uploade le fichier `index.html` de ce zip à la racine du dépôt (Add file → Upload files).
3. Va dans Settings → Pages.
4. Sous "Branch", choisis `main` et `/ (root)`, puis Save.
5. Après 1-2 minutes, l'adresse publique apparaît en haut de cette page, du type :
   `https://tonpseudo.github.io/carnet-a-points/`

C'est tout : le fichier `index.html` est autonome (HTML + CSS + JS), aucune installation nécessaire.
